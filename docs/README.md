# Swarmind documentation

> Spanish is the primary documentation language; this hub is bilingual for
> GitHub navigation.

Swarmind is a Python harness for coordinating AI coding agents with governed
fan-out, model routing, memory and evidence-driven validation.

## How this documentation is organised

We follow [Diátaxis](https://diataxis.fr/): four needs, four forms.

| Quadrant | What you get | Start here |
|---|---|---|
| **Tutorial** | Learn by doing, step by step | [`docs/src/es/guide/como-usar.md`](src/es/guide/como-usar.md) |
| **How-to** | Solve a specific task (install, GPU, publish, legal/RE workflows) | [`SETUP.md`](../SETUP.md) · [`docs/src/es/guide/estandares.md`](src/es/guide/estandares.md) |
| **Reference** | Look up agents, skills, API, specs | [`agents`](src/es/agents/INDEX.md) · [`skills`](src/es/skills/INDEX.md) · [`api`](src/es/api/) · [`specs`](specs/) |
| **Explanation** | Understand architecture and decisions | [`architecture`](src/es/architecture/swiss-watch.md) · [`research`](research/) · [`adr`](adr/) |

## Conventions

- **Agents (26)** and **skills (49)** are the source of truth in `.opencode/`;
  the indexes here are generated by `scripts/gen_docs_index.py`.
- Internal links are checked by `scripts/check_docs_links.py`.
- Specs describe *how* and *why* a capability exists; the roadmap tracks status
  and gaps.
