# Como Modificar Archivos

## Reglas
1. <900LC: Ningun archivo supera 900 lineas
2. No duplicar estandares: ya estan en agent prompts
3. DocStrings ES-UTF8: toda funcion publica documentada
4. Preservar paralelismo: nivel 0 siempre multi-agente
5. No romper ContextInjector: mantiene calidad constante
