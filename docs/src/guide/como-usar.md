# Como Usar AGENTIC

Simplemente escribe tu tarea en lenguaje natural. **No necesitas preambulo**.

## Ejemplos

| Tarea | Resultado |
|-------|-----------|
| implementa una API REST en Rust | Builder escribe API + Scientist investiga + Guardian testea |
| crea un modulo de trading | Todos los agentes en paralelo con calidad automatica |
| audita seguridad del codigo | Guardian audita + Builder corrige + Guardian verifica |
