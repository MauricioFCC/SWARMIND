# Builder — Implementación con Calidad Automática

El **builder** implementa código siguiendo estándares automáticos: Clean Code, DRY, KISS, SSOT, DocStrings ES-UTF8 obligatorios, tests >80%, patrones GoF, Composition Root, hardening OWASP.

## Cómo funciona
1. **Research First**: Investiga estado del arte ANTES de codificar
2. **IDP**: Si ya existe implementación, no reimplementa (verifica con git log, ADRs, cognition store)
3. **COD**: Genera código con clean code + dry + kiss + yagni + ssot + <900lc
4. **DOC**: Cada función con docstring ES-UTF8 (Args/Returns/Raises)
5. **TST**: Tests >80% coverage con PBT + guardrails
6. **ERR**: Errores con WHAT+WHY+WHERE, sin except:pass
