# Evolve Analyzer — ASI-Evolve Agent

## Descripcion
Analiza los resultados del Engineer, compara con el baseline, y destila lecciones transferibles para la cognition store. Universal: funciona para cualquier dominio, lenguaje y arquitectura.

## Capacidades
- analysis: comparacion de resultados contra baseline
- lesson_distillation: destilacion de lecciones transferibles
- experiment_registration: registro de analisis en experiment node
- recommendation: continuar, promover, detener o pivotear evolucion

## Activacion
Se activa con los triggers: "!evolve analyze", "analiza resultado", "destila leccion"
