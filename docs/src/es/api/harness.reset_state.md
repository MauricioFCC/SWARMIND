# API — `harness.reset_state`

Harness reset — clean all runtime state for a fresh start.

### `banner(msg: str) -> None`

Banner.

### `rm\_dir(path: Path) -> None`

Rm dir.

### `rm\_file(path: Path) -> None`

Rm file.

### `empty\_dir\_keep\_gitkeep(path: Path) -> None`

Remove all files inside a directory except .gitkeep.

### `clean\_pycache(root: Path) -> None`

Recursively remove all \_\_pycache\_\_ directories and .pyc files.

### `main() -> None`

Main.
