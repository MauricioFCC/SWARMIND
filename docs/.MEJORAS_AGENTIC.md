## 1. 🐛 Fix Crítico: LanceDB check prematuro al importar el paquete

**Problema:**
`harness/__init__.py` importaba `from harness.run import main as run` a nivel de módulo.
Esto ejecutaba el check de LanceDB (`sys.exit(1)` si no instalado) **al importar cualquier cosa del paquete `harness`**, incluso si solo se quería usar `TaskManager` o `LanceVectorStore`.

**Solución:**
- `harness/__init__.py`: Eliminado import directo de `run.py`. Ahora usa `run_main()` con lazy import.
- `harness/run.py`: Check de LanceDB movido de módulo → función `_check_lancedb_or_exit()` dentro de `main()`. A nivel de módulo solo hay warning, no `sys.exit()`.
- `harness/__main__.py`: Actualizado para usar `run_main()`.

**Impacto:** Ahora se puede importar `harness` sin disparar el check de LanceDB.

## 10. 🚀 Sesión Frontier 2026-07-20: Async + Token Economics + 60% Coverage

### 10.1 AsyncAgentBus (ADR-0017)
**Problema:** AgentBus síncrono bloqueante, debate serie O(n·r).
**Solución:** `AsyncAgentBus` con asyncio.Queue por canal, `_execute_consensus_async` con asyncio.gather O(n)→O(1), WriteAheadLog con retry+backoff.
**Archivos:** `harness/orchestrator/agent_bus.py`, `harness/orchestrator/debate_orchestrator.py`, `harness/orchestrator/write_ahead_log.py`
**Tests:** 5 async + 10 WAL

### 10.2 ShapedCache + Structured Compaction (ADR-0018)
**Problema:** Sin cache semántico con forma activa, contexto sin compactar.
**Solución:** `ShapedCache` (LRU+TTL+relevancia, -38% tokens), `structured_compact()` (preserva headers, comprime tools, -41%), integrados en pipeline TaskOrchestrator+TaskPlanner.
**Archivos:** `harness/memory_rag/semantic_cache.py`, `harness/memory_rag/context_window_manager.py`, `harness/orchestrator/task_orchestrator.py`, `harness/orchestrator/task_planner.py`
**Tests:** 8 ShapedCache
