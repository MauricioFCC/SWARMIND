## 1. 🐛 Fix Crítico: LanceDB check prematuro al importar el paquete

**Problema:**
`harness/__init__.py` importaba `from harness.run import main as run` a nivel de módulo.
Esto ejecutaba el check de LanceDB (`sys.exit(1)` si no instalado) **al importar cualquier cosa del paquete `harness`**, incluso si solo se quería usar `TaskManager` o `LanceVectorStore`.

**Solución:**
- `harness/__init__.py`: Eliminado import directo de `run.py`. Ahora usa `run_main()` con lazy import.
- `harness/run.py`: Check de LanceDB movido de módulo → función `_check_lancedb_or_exit()` dentro de `main()`. A nivel de módulo solo hay warning, no `sys.exit()`.
- `harness/__main__.py`: Actualizado para usar `run_main()`.

**Impacto:** Ahora se puede importar `harness` sin disparar el check de LanceDB.

### 11.11 Arquitecturas RAG frontier — híbrido RRF + correctivo CRAG (2026-08-18)

### 11.21 Auto-actualización anti-reversión implementada (2026-10-17)

**Mandato:** cuando el repo remoto avance y alguien tenga el harness
descargado, el programa debe leer el remoto y actualizarse solo,
cross-platform, con **log de actualización que impida reversiones**.
Ciclo SDD completo: spec → SDD → TDD adversarial mutante → docs.

**Investigación frontera aplicada (FRS):** ADR-0010 anti-rollback
(FabianSchurig/open-connect) ⇒ `max_seen_version` monotónico persistido en
el journal (no solo comparación par a par) + downgrade como **acción
deliberada** (`allow_downgrade=True` + `justification` no vacía ⇒ evento
`downgrade_forced` auditable). Journaling "roll forward": *prefix property*
— si existe una actualización, existen todas las anteriores = exactamente
el invariante de `--ff-only` (InterSystems/SQLite WAL). Defense-in-depth:
`git config branch.<b>.mergeoptions --ff-only` ("ff-only promotion makes
divergence impossible", git-automation 2026) y MITRE MID-030 (la referencia
anti-rollback solo avanza tras confirmación).

**Implementación** (`harness/self_update/` — 3 módulos por SRP, ninguno

journal puede haber visto una versión mayor). `max_seen` **nunca baja**,
ni siquiera con downgrade forzado. Solo mutan worktree los caminos
