# Science-Doc (min)
Dominio científico multidisciplina: papers, tesis, revisiones sistemáticas, investigación.

## Keywords
science, research, paper, thesis, experiment, hypothesis, peer review, systematic review, meta-analysis, reproducibility

## Reglas
1. Análisis estructural IMRaD: Introduction, Methods, Results, Discussion
2. Evaluación metodológica: diseño experimental (RCT, cohorte, caso-control), poder estadístico
3. Revisión bibliográfica: búsqueda sistemática, criterios inclusión/exclusión, PRISMA
4. Análisis de referencias: impacto, relevancia, actualidad, sesgo publicación
5. Reproducibilidad: verificar datos abiertos, código, pre-registro
6. Meta-análisis: heterogeneidad (I²), efectos fijos/aleatorios, funnel plot, sensibilidad
7. Síntesis: extraer hallazgos clave, limitaciones, conclusiones
