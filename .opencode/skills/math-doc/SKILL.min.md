# Math-Doc (min)
Dominio matemático/cuantitativo: análisis de papers, LaTeX, demostraciones, estadística, álgebra, cálculo.

## Keywords
math, theorem, proof, latex, equation, matrix, eigenvalue, gradient, convergence, estadística, teorema, demostración

## Reglas
1. Parseo LaTeX: preservar $..$, $$..$$, \(..\), \[..\]; unificar notación
2. Validación demostraciones: hipótesis→pasos→conclusión; detectar saltos lógicos
3. Análisis estadístico: test de hipótesis, valor-p, intervalos confianza, tamaño efecto
4. Álgebra lineal: operaciones matrices, descomposiciones (SVD, QR, Cholesky, eigen)
5. Cálculo: derivadas, integrales, EDOs, gradientes, optimización convexa
6. Probabilidad: distribuciones, teorema Bayes, procesos estocásticos, MC
7. Gráficas: redes, árboles, flujos, matching, teoría de grafos
8. Validación: consistencia notación, referencias cruzadas, estructura lógica
