# Education (min)

Diseno instruccional evidencia-basado: objetivos medibles (Bloom), evaluacion triple, andragogia, microlearning + spaced repetition.

## Principios esenciales
- Objetivo medible por unidad (nivel Bloom → verbo → evidencia).
- Evaluacion diagnostica + formativa + sumativa (+ autentica si el desempeno real importa).
- Alineacion Backward Design/ADDIE: resultado → evidencia → actividades.
- Microlearning (2-7 min, 1 objetivo/modulo) + spaced repetition (1→7→16→35 dias).
- Kirkpatrick: reaccion, aprendizaje, transferencia, resultados.

## Modelos (detalle en `references/modelos.md`)
ADDIE · SAM · Agile Learning · Backward Design; Bloom (6 niveles); tipos de evaluacion; Kirkpatrick (4 niveles).
