# Physical Sciences — Ciencias Naturales

## Descripcion
Skill de ciencias naturales para investigacion y analisis cientifico profundo.

## Responsabilidades
1. Fisica (mecanica clasica, cuantica, estadistica, relatividad)
2. Quimica (organica, inorganica, computacional, analitica)
3. Biologia (molecular, celular, evolutiva, sintetica)
4. Metodo cientifico y diseno experimental

## Comandos
- `!sci physics <problema>` — Analisis fisico
- `!sci chemistry <problema>` — Analisis quimico
- `!sci biology <problema>` — Analisis biologico
- `!sci experiment <diseno>` — Diseno experimental
