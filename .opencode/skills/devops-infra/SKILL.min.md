# DevOps & Infrastructure (min)

## Responsabilidades
- Infraestructura como codigo (Terraform, Pulumi)
- Contenedores y orquestacion (Docker, Kubernetes, Helm)
- CI/CD pipelines (GitHub Actions, ArgoCD)
- Monitoreo y observabilidad (Prometheus, Grafana)

## Comandos
- `!infra dockerize <app>` — Dockerizar aplicacion
- `!infra k8s <service>` — Configuracion Kubernetes
