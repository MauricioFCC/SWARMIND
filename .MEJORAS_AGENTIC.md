## 1. 🐛 Fix Crítico: LanceDB check prematuro al importar el paquete

**Problema:**
`harness/__init__.py` importaba `from harness.run import main as run` a nivel de módulo.
Esto ejecutaba el check de LanceDB (`sys.exit(1)` si no instalado) **al importar cualquier cosa del paquete `harness`**, incluso si solo se quería usar `TaskManager` o `LanceVectorStore`.

**Solución:**
- `harness/__init__.py`: Eliminado import directo de `run.py`. Ahora usa `run_main()` con lazy import.
- `harness/run.py`: Check de LanceDB movido de módulo → función `_check_lancedb_or_exit()` dentro de `main()`. A nivel de módulo solo hay warning, no `sys.exit()`.
- `harness/__main__.py`: Actualizado para usar `run_main()`.

**Impacto:** Ahora se puede importar `harness` sin disparar el check de LanceDB.
